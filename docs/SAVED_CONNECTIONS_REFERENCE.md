# Панель сохранённых подключений NetBox

Эталон — Far-NetBox на коммите `3db9ac303006fd905e294e65cd80e96319210066`, как в [аудите NET-03/04](audit/UI_NETWORK_ARCHIVES.md). Версия плагина на компьютере владельца остаётся открытым вопросом.

- Панель имеет один столбец имён. Группы — каталоги, образованные путём в имени сессии. В пустом списке плагин показывает подсказку о создании. [Режим панели](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L31-L88), [содержимое списка](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L595-L648).
- Enter подключает выбранную сессию, F4 открывает её параметры, а при отсутствии любых сессий создаёт новую. Shift+F4 открывает создание независимо от содержимого. Shift+F5 дублирует, Shift+F6 переименовывает. Диалог копирования или переименования принимает полный путь с группой и переводит курсор на результат. [Клавиши](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L1087-L1138), [переименование и копирование](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L684-L720), [создание и подключение](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L738-L837).
- F7 создаёт каталог. NetBox держит последнюю пустую группу до перехода между каталогами, а непустые группы выводит из сохранённых имён. Удаление группы обрабатывает все входящие сессии. [Создание каталога и обработка группы](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L2930-L3009), [удаление](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L3047-L3060).
- F5 экспортирует отмеченные сессии и содержимое отмеченных групп в выбранный каталог отдельными файлами `.netbox`. При копировании с противоположной файловой панели NetBox импортирует данные сессий. [Экспорт списка](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L3119-L3147), [формат экспорта](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L3350-L3379), [импорт](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L3517-L3654), [справка](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/NetBox.en.hlf#L94-L115).
- Отключение возвращает к сохранённым сессиям с запоминанием прежнего имени. [Disconnect](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPFileSystem.cpp#L3948-L4085).

Формат обмена — XML с корнем `NetBox`, коллекцией `Sessions` и элементами `Session`. Имя и строковые значения используют экранирование PuTTY. Редактор оригинала имеет действия OK, Connect и Cancel. [XML-хранилище](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/XmlStorage.cpp), [кодирование строк](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/core/HierarchicalStorage.cpp#L41-L109), [протоколы и параметры сессии](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/core/SessionData.cpp), [кнопки диалога](https://github.com/michaellukashov/Far-NetBox/blob/3db9ac303006fd905e294e65cd80e96319210066/src/NetBox/WinSCPDialogs.cpp#L4932-L4960).

## Границы переноса

- Старый `Connections.json` читается с прежними идентификаторами и именами. Сессии без поля группы остаются в корне, в том числе при наличии косой черты в старом имени. Для экспорта такого имени можно задать новый путь через Shift+F6.
- Обмен переносит адрес, порт, пользователя, начальную папку, таймаут и представимые настройки SFTP, FTP, явного FTPS и WebDAV. Пароли из XML игнорируются, пароль из Связки ключей в XML не попадает. Импорт создаёт новый идентификатор. В импортируемом списке совпадающие имена заменяются после подтверждения.
- SCP, S3, неявный FTPS, настройки прокси и SSH-туннелей, сертификаты и Windows/PuTTY-пути к ключам остаются открытыми. Экспорт с цепочкой SSH останавливается, чтобы не превратить маршрут через шлюзы в прямое подключение. Импорт поддерживает UTF-8, включая представление Unicode с BOM после снятия PuTTY-экранирования. Устаревшие системные кодовые страницы Windows не перенесены.
- Форма редактирования использует поля существующей формы FarForMac. Вкладки NetBox и расширенные параметры протоколов остаются открытыми в NET-06. Сопоставление с запущенным оригинальным плагином, включая обмен реальными экспортами NetBox, остаётся открытым.
