# Описания файлов: descript.ion

Локальные копирование, перемещение и групповое переименование автоматически сопровождают файлы их записями `descript.ion`. Настройка «Обновлять описания при файловых операциях» отключает это поведение. Отложенная операция сохраняет выбранные настройки вместе с запросом.

При копировании запись источника остаётся. При перемещении она удаляется только после успешной публикации копии и удаления исходного объекта. Пропуск конфликта, отказ до публикации и отмена копирования не меняют записи. Новое имя из диалога конфликта получает описание источника. При перезаписи обновляется только соответствующая запись; остальные строки сохраняют исходные пробелы, порядок и окончания строк. Если у источника нет записи, существующее описание назначения сохраняется.

Слияние папок переносит записи каждого реально обработанного дочернего объекта. Сам `descript.ion` не заменяется целиком: это уничтожило бы описания пропущенных объектов и объектов, существующих только в назначении. После перемещения полностью опустевший `descript.ion` удаляется. Исходная папка, содержащая оставшиеся записи или непустые строки оформления, сохраняется; итог сообщает об этом. Это сохраняет также строки о файлах, не входивших в операцию. При обычном копировании папки целиком её внутренний `descript.ion` копируется побайтно вместе с остальными файлами. Явно выбранный `descript.ion` обрабатывается как пользовательский файл, без автоматического редактирования самого себя; автоматическое сопровождение соседних выбранных файлов той же папки также отключается, чтобы не менять явно выбранные байты.

Ошибки описаний не запускают повтор уже выполненного копирования. Копия остаётся доступной, а итог помечается как частичный и содержит предупреждение. Если описание назначения записать не удалось, перемещение оставляет исходный объект. Ошибка удаления исходной записи после удаления файла оставляет прежнюю запись и предупреждение; автоматического отката пользовательских файлов нет. Для группового переименования учитываются только успешно переименованные имена; ошибка записи описаний сообщает количество уже выполненных переименований.

## Кодировка

В окне описания можно явно выбрать UTF-8, Windows-1251 или DOS-866. Успешный выбор запоминается для папки и используется панелью и следующими операциями. Выбор перечитывает файл; при несохранённых изменениях требуется согласие на их отмену. Выбор не преобразует файл на диске. Сохранение использует ту же кодировку и отказывает, если имя или текст невозможно представить без потери символов. Автоопределения по локали и замены неподдерживаемых символов на `?` нет.

UTF-8 BOM, исходные переводы строк, многострочные описания и кавычки в именах с пробелами поддерживаются. Ограничения: 2 МиБ / 20 000 строк, точное сопоставление имён, отсутствие управляющих символов и кавычек в именах. Неоднозначные повторяющиеся записи, повреждённая кодировка, ссылки и специальные объекты на месте `descript.ion` отклоняются с сохранением исходных байтов.

## Защита от конкурентных изменений

Снимок проверяет байты, inode, размер, права и времена изменения перед атомарной заменой, а также идентичность папки. Внешняя правка после начала операции не затирается. Используется файловая координация macOS; некоординирующийся внешний процесс всё ещё может попасть в узкий промежуток между последней проверкой и заменой — файловая система не предоставляет сравнение-и-замену по версии. Несколько `descript.ion` не образуют общей транзакции: назначение записывается раньше удаления записи источника.

## Сверка с FAR

Проверенная версия FAR: `1a6b02544b339615232078e0551463ef15b73ff9`.

- [far/copy.cpp](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/copy.cpp): `SetDestDizPath` учитывает режимы never / if displayed / always; `CopyDiz` вызывается после успешного копирования, `DeleteDiz` после перемещения. Здесь выбран режим автоматического обновления с явным отключением.
- [far/dizlist.cpp](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/dizlist.cpp): `CopyDiz` оставляет назначение без изменений при отсутствии описания источника; чтение поддерживает кавычки и продолжения строк, сохранение учитывает кодировку. В macOS кодировка выбирается явно вместо системной ANSI/OEM.

Это локальные операции. Передача описаний через FTP/SFTP/WebDAV, произвольные имена файлов описаний и полный набор опций FAR не реализованы этим механизмом.
