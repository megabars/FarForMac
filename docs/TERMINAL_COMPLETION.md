# Терминальный экран

## Эталон

В FAR на коммите `1a6b02544b339615232078e0551463ef15b73ff9` команда активирует пользовательский экран Windows Console. Пустой Enter прокручивает экран без добавления строки, запуск идёт через `Execute`, а выход восстанавливает экран и обновляет панели. Справка назначает Ctrl+O для скрытия и возврата обеих панелей. [Исходник FAR](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/cmdline.cpp#L1128) · [Справка FAR](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/FarEng.hlf.m4#L360)

FarForMac передаёт внешней программе управляющий macOS PTY. Программа получает размер в строках и колонках, а ввод и управляющие команды используют протокол xterm. Для терминального протокола эталон — xterm control sequences. Основной экран может объединять только автоматически перенесённые строки при изменении ширины. Альтернативный экран сохраняет адресуемые строки и отдаёт перерисовку программе через изменение размера PTY. Границы кластеров использует Swift, свойства ширины — Unicode, East Asian Ambiguous занимают одну колонку. [XTerm Control Sequences](https://raw.githubusercontent.com/ThomasDickey/xterm-snapshots/master/ctlseqs.txt) · [UAX #11](https://www.unicode.org/reports/tr11/) · [UAX #29](https://www.unicode.org/reports/tr29/)

OSC обрабатывается как недоверенный поток. Запросы цвета ограничены терминальной палитрой, метаданные не открывают ссылки, не пишут в clipboard, не запускают команды и не меняют каталог панели. Ввод клавиш и мыши возможен в активном терминале, отчёты мыши отправляются по режиму, явно установленному запущенной программой.

## Реализованный контракт

- Основной буфер хранит границы мягких переносов. Resize перераскладывает целые кластеры с их цветами и фоном, сохраняет явные разрывы, позицию курсора и сохранённую позицию. При узком resize длинная строка может продолжиться в ограниченной истории, а ячейка шириной в один столбец удерживает широкий кластер целиком до расширения. При уменьшении высоты содержимое за нижней границей окна сохраняется в пределах видимого буфера, если помещается вместе с курсором.
- Альтернативный буфер обходится без истории. 47 сохраняет его содержимое между переключениями, 1047 очищает при выходе, 1048 сохраняет и восстанавливает курсор, 1049 очищает при входе и восстанавливает состояние основного экрана при выходе. При resize приложение передаёт PTY новый размер для перерисовки. Завершение дочернего процесса возвращает основной экран и сбрасывает режимы ввода.
- Поддержаны DEC special graphics, origin mode, autowrap, application keypad, вставка символов, табуляторы, форма и видимость курсора, отчёты о позиции, режимах и размере в символах. Ограниченный DECRQSS отвечает на запросы SGR, вертикальных полей и формы курсора.
- OSC 0/1/2/7 хранит метаданные, CSI 22/23 поддерживает ограниченный стек заголовков. OSC 4/104 меняет индексированную палитру, 10–12/110–112 управляет цветами по умолчанию и цветом курсора. Ответы о цветах содержат только значения терминала.
- F1–F12, стрелки, Home/End, Page Up/Down, Insert/Delete, Shift+Tab и цифровая клавиатура отправляют байты xterm. Shift/Option/Control кодируются для специальных клавиш. Текстовые символы, создаваемые Option и IME, идут через штатный ввод AppKit. Ctrl+O переключает пользовательский экран.
- Мышь работает в режимах 9, 1000, 1002 и 1003, включая движение и колесо там, где их запрашивает режим. Кодировки 1005, 1006, 1015 и 1016 поддерживают расширенные координаты. 1004 включает отчёты о фокусе, 1007 управляет прокруткой альтернативного экрана стрелками. Cmd удерживает локальное выделение текста. Отчёты терминала не помечают командную строку управляемого zsh как ручной ввод.
- AppKit использует те же размер ячейки и высоту строки для вывода, курсора, мыши и расчёта размера PTY. Глифы запасных шрифтов получают поправку к ширине, а форматированный текст остаётся доступным для выделения и копирования.

## Проверки и открытые границы

`TerminalFullscreenTests` запускает системные Vim и less в реальном управляющем PTY. Vim получает F5, Shift+F6, SGR-щелчок и изменение размера, затем возвращает основной экран. less листает страницу вперёд и назад по Page Down/Page Up, затем возвращает исходный вывод. Дополнительные тесты ядра покрывают потоки UTF-8, reflow, DEC-буферы, OSC-палитру и форматы мыши.

Открыты полная совместимость xterm и произвольных TUI, пиксельные отчёты окна, DECSLRM, highlight mouse mode 1001, расширенные клавиатурные протоколы, Sixel, гиперссылки OSC 8 и clipboard OSC 52. Ширина зависит от версии Unicode/ICU на системе, а форма и читаемость глифов — от шрифта AppKit. Сценарии Windows Console остаются за пределами macOS PTY.
