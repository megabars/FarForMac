## Реализация FarForMac

«Панели → Добавить выбранное во временную соседнюю панель» собирает пометки, либо курсор при отсутствии пометок. Источники разных папок видны с колонкой полного исходного каталога. Повторное добавление того же пути сохраняет первый снимок: новый объект на месте старого не принимается автоматически. Добавление папки не разворачивает её содержимое. Поиск продолжает отправлять результаты в тот же вид панели.

F7 и отдельная команда убирают только записи. F5/F6/F8 продолжают работать с исходниками; одноимённые назначения проверяет существующая очередь операций. Ctrl+PageUp и «Перейти к исходной папке» открывают обычную папку с курсором на объекте. Возврат восстанавливает прежние колонки, сортировку, фильтр и курсор.

Сессия — собственная адаптация: при обычном выходе или явном «Сохранить сессию панелей» сохраняются режим, путь, курсор, фильтр, исходный контекст и до 10 000 снимков временной панели, максимум 8 МиБ на панель. Активная сторона, обычные колонки/ширины, сортировка и пути используют существующие настройки приложения. После перезапуска снимки повторно проверяются; удалённые, заменённые или изменённые объекты исключаются с числом недоступных записей. Пометки намеренно не восстанавливаются после запуска, чтобы случайно не выполнить операцию над старым набором.

## Оставшиеся отличия

Общие панели 0–9 реализованы в описанных ниже границах. Остаются оригинальный формат `.temp`, опции AnyInPanel/SafeMode FAR и добавление всего содержимого папки. Это встроенный режим, а не бинарно совместимый плагин. После аварийного завершения используется последняя явно сохранённая сессия; новые несохранённые временные записи могут отсутствовать. Раскрытие ветвей дерева не сохраняется. Защита снимков консервативна: изменение файла требует повторного добавления/поиска после удаления устаревшей записи.


## Десять общих панелей — R14.1

Отдельное окно «Общие временные панели · 0–9» содержит десять независимых слотов. «Сохранить текущую» записывает ссылки активной временной панели в выбранный слот; «Добавить текущую» объединяет списки по полному пути. Заполненный слот при замене требует явного выбора. «Открыть» или двойной щелчок показывает выбранный слот на активной панели; сам показ окна и загрузка хранилища не открывают панели или файлы. Пустой слот открывается как пустая временная панель. Очистка слота убирает только ссылки, сохраняя реальные файлы.

Открытая общая панель показывает номер слота. Удаление ссылок F7, добавление записей, исключение устаревших источников при обновлении и выход из общей панели сохраняют её список. Переключение через окно также сохраняет текущий связанный слот. Изменение слота синхронизирует обе открытые файловые панели этого номера; устаревшая копия на второй стороне не возвращает удалённые ссылки. После перезапуска библиотека выбирает последний номер, но не открывает его автоматически. Обычная сессия панели может восстановить собственный временный снимок без связи с общим слотом: для дальнейшего общего редактирования откройте номер через окно библиотеки.

Хранилище `~/Library/Application Support/FarForMac/TemporaryPanels/panels.json` — собственный JSON версии 1: ровно десять списков, максимум 10000 записей на слот и 32 МиБ на библиотеку. Папка имеет `0700`, файл — `0600`, владелец — текущий пользователь. FIFO, символические ссылки, общедоступные и чрезмерно большие файлы отклоняются без блокирующего чтения. Запись атомарна; сравниваются исходные байты и идентичность файла, размер и времена изменения. Внешне изменённый, удалённый или заменённый после загрузки файл не перезаписывается: ошибка предлагает перечитать библиотеку. Повреждённое хранилище не заменяется пустым.

Сохраняются исходные `SearchResult`, включая inode/device, размер, наносекундное время и stamp содержимого для результатов поиска. Переключение и перезапуск не вызывают повторный захват текущего пути. При добавлении или сохранении того же пути первый снимок в слоте сохраняется: подменённый объект не становится доверенным. Для сознательного повторного захвата сначала явно очистите слот и заново добавьте нужный источник из файловой панели/поиска. Перед файловыми действиями действует существующая проверка `verifyCurrent`; удалённые/заменённые источники не принимаются автоматически.

Повторно прочитаны закреплённые [TmpEng.hlf:47](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/plugins/tmppanel/TmpEng.hlf#L47) (Use common panel, 10 списков, меню Alt+Shift+F12, Alt+Shift+0…9) и [TmpClass.cpp:753](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/plugins/tmppanel/TmpClass.cpp#L753) (`SwitchToPanel`, `ProcessPanelSwitchMenu`, `IfOptCommonPanel`) через GitHub. Перенесено поведение отдельных списков и явного переключения; формат и сохранение на диск — самостоятельная адаптация macOS. Точные аппаратные сочетания FAR не требуются для доступа: доступно обычное меню приложения и отдельное окно.

## Переносимые списки путей — R14.1

Меню «Панели → Импорт списка во временную панель…» читает явный локальный файл: JSON версии 1 (`version`, `paths`), UTF-8 строки либо NUL-разделённый `.lst0`. Относительные пути отсчитываются от папки списка; нет shell, glob и подстановки переменных. До 10000 путей и 8 МиБ; обычные файлы, без FIFO/конечной ссылки. Недоступные пути считаются и пропускаются, остальные получают свежий снимок только при явном импорте; повторное добавление пути сохраняет прежний снимок.

«Экспорт списка путей…» записывает JSON: всю временную панель либо выбранные объекты обычной. Это переносимые пути, а не исполняемое меню. JSON сохраняет Unicode/кавычки/переводы строк в именах. Импорт переносимого списка намеренно отличается от сохранения общих слотов: общие слоты хранят исходные идентичности и не подменяют исчезнувший файл новым.

Сверены `TmpEng.hlf` (списки/10 общих панелей, строки 25–57) и `TmpClass.cpp::ProcessSaveListKey/SaveListFile` (660–740) закреплённого FAR. Windows-кодировки, команды/меню внутри list-файлов и полная конфигурация TmpPanel не заявлены.

## Смешанные результаты — R9.3

Кнопка «Во временную панель» общего поиска сохраняет типизированные ссылки на конкретные локальные файлы, члены архивов и сетевые объекты. Enter/F3/F4 используют исходный источник, F5 копирует в обычную папку через очередь, F7/F8/Delete убирают только ссылки. R14.3 сохраняет последний смешанный список и общие слоты между запусками; открываются они через меню без доступа к источникам. Подробности и пределы — [MULTISOURCE_SEARCH_REFERENCE.md](MULTISOURCE_SEARCH_REFERENCE.md).

## Постоянные смешанные панели — R14.3

Меню «Общие временные панели · 0–9» теперь открывает смешанную библиотеку. Старые локальные снимки переносятся один раз; файл `panels.json` остаётся без изменений. Сохранить/добавить можно локальную временную или смешанную панель; открыть слот можно без доступа к источникам. Поведение восстановления и оставшиеся ограничения описаны в [PERSISTENT_PANELS_REFERENCE.md](PERSISTENT_PANELS_REFERENCE.md).
