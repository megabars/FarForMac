## Интерфейс

«Свойства и права…», в том числе F4 для папки, показывает POSIX-права, дату доступа и дату изменения. Флажки явно выбирают изменяемые поля. Даты задаются в текущем часовом поясе; невыбранная дата сохраняется через `UTIME_OMIT`. Поддерживаются обычные локальные файлы и папки. Также показаны имя/UID владельца и имя/GID текущей группы. Владелец доступен только для чтения: назначение другого UID требует повышенных прав, которые приложение не запрашивает. Флажок «Изменить группу» и список имён/GID позволяют выбрать эффективную или дополнительную группу текущего пользователя. Эта операция разрешена только для объектов, принадлежащих текущему пользователю; чужой объект в рекурсивном дереве останавливает подготовку целиком. При применении принадлежность объекта и членство в группе проверяются повторно. `fchown` изменяет только GID, сохраняя UID. ОС может снять set-ID биты при смене группы; приложение не восстанавливает их скрытно. Если явно выбраны POSIX-права, они применяются после смены группы. Время создания, системное время смены метаданных, ACL и атрибуты Windows через этот интерфейс не редактируются.

Флажок вложенных объектов распространяет **все явно выбранные изменения** — POSIX-права, дату доступа, дату изменения и группу — на каждый объект подготовленного списка. Даты можно менять рекурсивно без изменения прав. Без флажка изменения действуют только на выбранный объект. Одинаковое восьмеричное значение назначается файлам и папкам: пользователь должен сохранить биты поиска/исполнения папок, если хочет продолжать их обход. Сначала требуется «Предпросмотр изменений», затем отдельное подтверждение подготовленного плана. Изменение любого поля сбрасывает план. Перечень содержит старые права, UID/GID, выбранные прежние даты и пути, новые значения, число пропущенных ссылок/спецфайлов/других томов/повторных hardlink. Для больших деревьев интерфейс показывает первые 200 путей и явно указывает полное число: применяется весь подготовленный план. Прогресс интерфейса обновляется не чаще 20 раз в секунду, плюс завершение.

Подготовка и применение выполняются в фоне. «Отмена» останавливает работу между объектами; отчёт показывает завершённое число, отмену или ошибку. Уже выполненные изменения сохраняются. Текущий объект при ошибке между записью даты и прав мог измениться частично. Во время записи окно нельзя закрыть; после отмены или завершения доступны итоговый отчёт и новый предпросмотр.

## Гарантии и пределы

`MetadataMutation` строит полный план до первой записи: до 100000 посещённых объектов и 128 уровней. Ссылки и специальные файлы пропускаются без открытия их целей; переход на другой том не выполняется. Обычные файлы с одинаковыми device/inode включаются один раз. Изменение inode распространяется на **все** его жёсткие ссылки, в том числе вне выбранного дерева: hardlink не является независимой копией метаданных.

Обход использует дескрипторы папок, `openat`/`fstatat`, `O_NOFOLLOW` и проверку device/inode/типа/прав/UID/GID/размера/числа ссылок/mtime/ctime. Проверка ctime отклоняет изменение содержимого даже с восстановленным mtime. Обычное чтение может обновлять atime средствами файловой системы; поэтому atime сам по себе не является причиной конфликта. В пути к исходному объекту также запрещены символические ссылки после канонизации родителя. Перед первой записью повторно проверяется весь план, затем каждый открытый дескриптор непосредственно перед `fchown`/`fchmod`/`futimens`. Каталоги обрабатываются после потомков, чтобы снятые права поиска не ломали ещё не выполненную часть плана. Новые объекты после предпросмотра не включаются автоматически; внешние изменения приводят к отказу или частичному отчёту, а не к обходу нового дерева.

Операция выполняется с обычными правами пользователя, без повышения привилегий. Невозможность открыть или изменить объект сообщается; недоступные деревья не объявляются успешно обработанными. Дескриптор защищает от перенаправления через подменённую ссылку, но не запрещает параллельные изменения тем же владельцем и не создаёт транзакцию для всего дерева. Отмена и ошибка не откатывают прежние шаги. Прямое редактирование ACL, смена UID владельца, Windows security descriptors, время создания/смены метаданных и полный паритет диалога FAR остаются открытыми.

Проверки `MetadataMutationTests`: сохранение невыбранной даты и прав, точность долей секунды, неизменность байтов, рекурсивный порядок, ссылки/цикл/FIFO, hardlink и рекурсивные даты потомков, даты без изменения прав, сохранение mtime при изменении только atime, нерекурсивные даты, отказ изменённому плану до первой записи (включая восстановленный mtime, замену папки ссылкой и новую hardlink), разрешённая смена группы без смены UID/дат/байтов, отказ группе вне членства пользователя, отмена до старта и после первого шага, недопустимые настройки. AppKit smoke проверяет элементы владельца/группы, отсутствие записи до подтверждённого применения и фоновое применение рекурсивных прав/дат/группы в изолированном каталоге. Результаты запуска фиксируются отдельно в приёмке; наличие теста не заменяет его выполнение.
