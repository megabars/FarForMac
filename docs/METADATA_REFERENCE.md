## Поддерживаемый формат описаний

```text
README.md Документация
"отчёт за октябрь.txt" Отчёт по проекту
 Продолжение описания
```

Поддерживается строгий UTF-8 с BOM или без BOM. Новые файлы используют CRLF; редактирование использует окончание строки исходного файла. Пустое описание удаляет запись. В отличие от FAR, автоматическое угадывание ANSI/OEM, DOS-короткие имена и удаление префикса размера не реализованы. Некорректные UTF-8, неоднозначные повторные записи, незакрытые кавычки и продолжения без записи отклоняются без записи на диск. Для имён используются точные Unicode-строки; автоматического сведения регистра нет. Кавычки, управляющие символы и разделитель пути в имени нельзя записать этим форматом. Пустые строки внутри нового многострочного описания отклоняются, поскольку FAR пропускает их при чтении.

Загрузка ограничена 2 МиБ и 20 000 строками; одно редактируемое описание — 64 КиБ. Обычные файлы читаются с `O_NOFOLLOW | O_NONBLOCK`: ссылки, FIFO и каталоги не читаются и не заменяются. При сохранении сверяются байты, inode, размер, режим, времена изменения и идентичность каталога; проверяется также появление файла, которого не было при чтении. Сохраняются права, ACL и расширенные атрибуты существующего файла. Неподчиняющийся файловой координации сторонний писатель может попасть в короткий промежуток между последней проверкой и rename: абсолютной операции compare-and-swap для обычного файла здесь нет. Операции копирования/переноса файлов пока не переносят записи описаний автоматически.

## Настройки групп

Редактор проверяет JSON целиком и применяет настройки только после успешной проверки:

```json
{
  "enabled": true,
  "upper": ["README*", "<source>"],
  "lower": ["*.tmp;*.bak"]
}
```

Первое совпадение выигрывает, включая пересечение верхней и нижней групп. Доступны те же glob, исключения, группы `<имя>` и явные регулярные выражения, что в фильтре. Не более 100 правил, каждое до 4096 UTF-16 единиц; JSON до 512 КиБ. Ранги вычисляются до сортировки под общим временным бюджетом, ошибка не оставляет частично применённый порядок. Более сложные фильтры FAR по времени/атрибутам в этой версии не реализованы.

Автоматические проверки: `FileDescriptionsTests` (сохранность нетронутых записей, Unicode/кавычки/продолжения, удаление, отсутствие лишней записи, конфликт существования и идентичности, ссылки/FIFO, неверный формат, ограничения, права); `SortGroupsTests` (приоритет и первое совпадение, общие маски, JSON, валидация и общий бюджет).
