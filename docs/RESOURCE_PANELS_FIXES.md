# Исправления R20: панели ресурсов и действия над результатами

Эталон: FAR `1a6b02544b339615232078e0551463ef15b73ff9`, ссылки и прочитанные обработчики — [аудит UI](audit/UI_NETWORK_ARCHIVES.md), [аудит файлов](audit/FILES_SEARCH.md). Дополнительный NetBox — `3db9ac303006fd905e294e65cd80e96319210066`.

## Контракт

- `filelist.cpp:3168–3195` вызывает ChangeDisk для конкретной панели по мыши; `diskmenu.cpp:1266–1282` открывает плагин с LEFT/RIGHT-контекстом. Ресурс должен открываться на выбранной стороне, даже если фокус позднее сменился.
- Network, NetBox и ProcList — отдельные ресурсы. Первые два нельзя объединять в форму SSH.
- ProcList: `ProcEng.hlf:5–33`, `Proclist.cpp:209–243`, `Plist.cpp:181–209`: процессный список является панелью, F3 показывает сведения, Enter активирует приложение, F8 завершает процесс, Shift+F1/F2 меняют приоритет.
- TmpPanel: F5 на временную панель добавляет ссылки; F7 удаляет ссылки, F8 удаляет оригиналы. Операции смешанной панели должны работать с типизированными исходниками, не с временными копиями и не со скрытым локальным каталогом.

## Реализация текущего пакета

Для каждой панели добавлена собственная кнопка «Диск». Меню сохраняет ссылку на свою сторону; Alt+F1/F2 используют тот же маршрут. Специальные представления используют один контейнер панели с собственными focus/refresh/stop, без доступа файловых команд к скрытым объектам обычной панели.

Отдельные компоненты:
- [Сохранённые соединения](SAVED_CONNECTIONS_REFERENCE.md).
- [Локальная сеть SMB](LOCAL_NETWORK_REFERENCE.md).
- Процессы: панель с периодическим обновлением, F3 открывает текстовые сведения в просмотрщике, Enter активирует NSRunningApplication, F8 подтверждает завершение одного процесса; Shift+F1/F2 меняют macOS nice.

Для мутаций процессов PID связывается со временем старта ядра **до и после** сбора ps; изменившиеся/недоступные записи нельзя изменять. Идентичность повторно проверяется непосредственно перед операцией; PID 0/1 и собственный процесс защищены. Проверка и kill/setpriority на публичных macOS API не являются одной атомарной операцией: остаточное окно повторного использования PID явно остаётся ограничением. Windows-классы приоритета, WMI, удалённые процессы, handles и Windows-счётчики не перенесены. Значения CPU/RSS подписаны как macOS-метрики.

F5 в локальную временную панель добавляет проверенные ссылки. F8 смешанного списка проходит восстановление источников, подготовку плана, подтверждение и повторную проверку. Удаляются реальные локальные/архивные/сетевые объекты; из списка убираются только подтверждённо обработанные ссылки. При частичной ошибке уже выполненные удаления не откатываются, оставшиеся ссылки сохраняются.

## Открыто

Структура и маршрутизация F9 перенесены в [отдельном пакете](FAR_MAIN_MENU_REFERENCE.md). Полный drive menu FAR (F3/F4/F9 и параметры томов/плагинов), полное наполнение F9 и десять режимов панели, восстановление специальных панелей при запуске, полные настройки NetBox/Network/ProcList и остальной R20 не закрываются наличием этих компонентов. Диалоги AppKit ещё требуют визуального сопоставления с оригиналом. Работа LAN требует проверки с настоящим SMB-сервером и разрешениями macOS.

Полный прогон 702 тестов в 69 наборах и 178 AppKit-проверок прошёл; подробности — в [журнале приёмки](ACCEPTANCE.md). Этот документ не объявляет R20 завершённым.
