# Пользовательское меню и CommandX

Эталон FAR закреплён на `1a6b02544b339615232078e0551463ef15b73ff9`.

- F2 проверяет файл `FarMenu.ini` текущей папки. Если файла нет, открывает меню установки и затем профиля. Shift+F2 меняет источник в этом порядке. Backspace из локального меню ищет файл в родительских папках, сохраняя папку панели. [usermenu.cpp](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/usermenu.cpp#L348-L527)
- Формат хранит клавишу и заголовок, вложенные блоки в фигурных скобках, разделители `--:` и отдельные строки команд с отступом. Заголовок разворачивается без диалога ввода. [Чтение и запись файла](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/usermenu.cpp#L178-L266) · [Заголовки и клавиши](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/usermenu.cpp#L537-L589)
- CommandX пропускает строки `REM` и `::`, разворачивает параметры каждой команды перед запуском и вызывает диспетчер по одной строке. Отмена параметров прекращает последовательность. [usermenu.cpp](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/usermenu.cpp#L780-L866)
- Метасимволы имени, каталога, выбора, списка и ввода применяются в меню и ассоциациях. Префиксы активной, пассивной, левой и правой панели действуют до следующего переключения. [Справка FAR](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/FarEng.hlf.m4#L2310-L2421)

## Реализация FarForMac

- F2 открывает `FarMenu.ini` активной папки. При его отсутствии проверяется прежний `.farformac-menu.json`. Следующие источники — `FarMenu.ini` рядом с установленным `.app`, `FarMenu.ini` в профиле `~/Library/Application Support/FarForMac` и прежний `commands.json` профиля. Shift+F2 меняет источник, Backspace ищет локальное меню предка. Текущая папка панели служит начальной рабочей папкой при запуске пункта из любого источника.
- F4, Ins, Del и Ctrl+стрелки меняют открытый файл. Alt+F4 редактирует его исходный текст. Поддерживаются UTF-8 и UTF-16 с BOM. При сохранении сохраняется исходная кодировка, проверяется изменение файла с момента открытия. Правка отдельного пункта пересобирает структуру меню. Импорт в JSON сохраняет исходные строки, включая CommandX, и текущие ассоциации. Открытие и импорт только читают файл. Команды запускаются после выбора пункта.
- CommandX отправляет каждую строку в действующий диспетчер команд. Ненулевой статус позволяет выполнить следующую строку. Отмена параметров, Ctrl+C, остановка или ошибка подготовки прекращают последовательность. Буквальный `cd` меняет рабочий каталог следующей строки. В постоянном zsh между строками сохраняется окружение. В обычном режиме каждая внешняя строка получает собственную PTY, вывод виден в одном экране.
- Заголовки раскрывают имя, основу, расширение, текущую папку и выбранные имена. Команды используют активную, пассивную, левую и правую панели, исходные и разрешённые через ссылки пути каталогов, в том числе каталог одной панели с именем другой. Подстановки имён и ответов передаются как отдельные аргументы с POSIX-кавычками. Для списков реализованы `F/Q/S/U/W`, UTF-8 по умолчанию и UTF-16LE с BOM для `W`. Строки списка разделяются LF.
- Единственная применимая ассоциация выполняется сразу. При нескольких применяется меню выбора по порядку конфигурации. Выбор ассоциации запускает команду после её интерактивных параметров.

## Открытые части паритета

- Windows cmd/batch, префиксы FAR и командные условия, regexp-группы ассоциаций, Windows-кодировки ANSI/OEM, имена 8.3, описания файлов, история интерактивных параметров и вложенные метасимволы в запросах. Подстановки внутри произвольных составных POSIX-слов остаются ограничены.
- Диспетчер ещё не воспроизводит Windows console, автоматическое окружение Windows и все префиксы плагинов. Обновление экрана между строками CommandX не расширяет набор VT/xterm-режимов. Точная Unicode-геометрия и reflow, расширенные DEC/OSC, мышь и паритет полноэкранных программ остаются открыты.
- Исходные макросы FAR на Lua/MoonScript, макробраузер, события, `Keys`, `Plugin.Call` и совместимость с API поставляемых плагинов остаются отдельными задачами. Текущий JSON-механизм продолжает обслуживать существующие команды FarForMac.
