# Сеть и список процессов в выборе диска

> **Статус 05.11.2026:** описанная ниже реализация не соответствует исходному панельному сценарию FAR. R19.1 переоткрыт: нужны отдельные входы каждой панели, разделение LAN/NetBox и панель процессов. Проверенные исходники и критерии — [аудит](FAR_AUDIT_2026-11-05.md), UI-01/NET-01/PROC-01. Текст ниже описывает текущее состояние, а не согласованную замену FAR.

Сверка FAR: ревизия `1a6b02544b339615232078e0551463ef15b73ff9`.

- [Proclist.cpp:209–238](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/plugins/proclist/Proclist.cpp#L209) регистрирует Process List в меню плагинов и дисков; показ в дисках зависит от `Opt.AddToDisksMenu`.
- [ProcEng.hlf:5–28](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/plugins/proclist/ProcEng.hlf#L5) описывает список, завершение F8, переход к окну Enter, подробности F3, удалённый компьютер F6 и смену приоритета Shift+F1/F2.

В FarForMac кнопка «Диски», меню «Тома» и Alt+F1/Alt+F2 показывают «Сеть…» и «Процессы…». Сеть вызывает существующий диалог профилей SFTP/FTP/FTPS/WebDAV, подключение начинается только после подтверждения. Это вход к нашим провайдерам, а не Windows Network Neighborhood.

«Процессы…» открывает отдельное окно локальных процессов macOS. Колонки: имя, PID, усреднённая загрузка CPU, резидентная память RSS, UID. При выборе доступны PPID и полный путь. Есть фильтр имени/пути/PID, числовая сортировка и ручное обновление ⌘R. Показан снимок; процесс может завершиться до следующего обновления. CPU и RSS соответствуют macOS `ps`, не счётчикам Windows и не показателю memory footprint из Activity Monitor.

Снимок получает системный `/bin/ps` без shell, аргументов пользовательских команд и окружений процессов. Сбор идёт в фоне, ограничен пятью секундами, 8 МиБ и 20 000 строками; закрытие окна отменяет сбор. Ошибка доступа видна и очищает старый список. Никакие выбранные процессы не завершаются и не меняют приоритет. Разбор проверяет числовые поля, переполнение, дубли PID и имена с пробелами. Для формата прочитана локальная системная справка `/usr/share/man/man1/ps.1`.

Остатки R19: безопасное завершение с проверкой идентичности вместо одного PID, приоритеты, подробные сведения, активация окна и удалённые процессы. Встраивание процесса как виртуальной файловой панели FAR и Windows-специфичные данные не реализованы.
