# Локальные файловые операции

Сверка перед реализацией выполнена по FarGroup/FarManager на коммите
`1a6b02544b339615232078e0551463ef15b73ff9`. Встроенная справка прочитана из
локального снимка, участки C++ проверены через GitHub Contents API по тому же
коммиту.

- Диалог копирования и переноса содержит путь, политику совпадений, сохранение времён, обход ссылок, несколько назначений и фильтр. Три сочетания для дерева выбирают начальную папку. Shift+F5 и Shift+F6 начинают с имени объекта под курсором. Форма F6 блокирует список назначений, хотя справка описывает его и для переноса. [Диалог и исходные значения](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/copy.cpp#L501-L850)
- Существующая папка принимает объект внутрь. Для одного источника новый путь задаёт конечное имя, завершающий разделитель принудительно обозначает папку назначения. Копирование по списку использует запятые и точки с запятой вне кавычек. `ConvertWildcards` вызывается для каждого исходного имени в обычной операции. [Справка](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/FarEng.hlf.m4#L4665-L4765), [Преобразование имён](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/copy.cpp#L1390-L1439)
- При совпадении FAR предлагает замену, пропуск, переименование и добавление, запоминает выбор на время операции и даёт F3 для источника и назначения. «Только более новые» сравнивает время записи. Для файла только для чтения действует отдельное решение. [Конфликт и повторное подтверждение](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/copy.cpp#L2987-L3247)
- Первое обычное правило фильтра может быть переопределено первым совпавшим приоритетным правилом I/X. Если фильтр исключил всё содержимое, папка назначения не создаётся. При переносе непустая исходная папка сохраняет исключённые объекты. [Сопоставление фильтров](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/filefilter.cpp#L588-L695), [Копирование и фильтр](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/FarEng.hlf.m4#L4756-L4764), [Удаление исходника](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/copy.cpp#L2458-L2483)
- Ctrl+A обрабатывает явно изменённые атрибуты и поля дат. Владелец применяется отдельно. Выбранные изменения могут распространяться на подкаталоги. [Справка](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/FarEng.hlf.m4#L4063-L4113), [Применение](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/setattr.cpp#L759-L815), [Обход](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/setattr.cpp#L1520-L1609)

## Границы реализации macOS

- Диалог локальных F5/F6 использует выбор папки AppKit. При одном источнике и одинаковых папках панелей поле назначения начинается с имени объекта. Список копирования отклоняет повторяющиеся конечные пути после подстановки масок и имён источников, включая совпадения через символьные ссылки на папки и регистр на томе. Проверка выполняется перед добавлением в очередь и сохраняет введённые пути для выполнения.
- В новом каталоге после копирования по фильтру `descript.ion` содержит записи опубликованных объектов. При переносе исходная копия описаний сохраняется до завершения удаления данных. Из неё удаляются записи только тех объектов, которых больше нет по исходному пути. Если очистка прервана или исходный файл описаний изменился, исходные записи сохраняются. Поведение для отдельного явно выбранного `descript.ion` остаётся файловой операцией.
- Изменения времени создания, BSD-флагов Hidden/NoDump и ACL используют собственные возможности файловой системы. Изменение UID требует уже имеющихся прав root. Редактирование ACL применяется к одному выбранному объекту после предпросмотра. Поддержка свойств для нескольких одновременно отмеченных корней, изменение `ctime`, рекурсивные ACL и Windows-атрибуты остаются открытыми.
- Обход целей символических ссылок при копировании, прямой перенос на одном томе и варианты наследования прав FAR остаются открытыми. Копирование и перенос локальных ссылок используют текст ссылки. Локальные переносы публикуют проверенную копию перед удалением источника.
- При снятом флажке сохранения всех времён FAR передаёт только время записи. macOS применяет время записи исходника и текущее время доступа. `copyfile` может также перенести время создания в составе метаданных. Точное соответствие остальных времён остаётся открытым. [Установка времени в FAR](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/far/copy.cpp#L242-L254)
