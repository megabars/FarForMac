Конкретный проверенный пример — [Panel.SpaceToSelect.lua:1–11](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/extra/Addons/Macros/Panel.SpaceToSelect.lua#L1): область `Shell`, клавиша Space, условие пустой командной строки и видимости панели, действие `Keys('Ins')`. В FarForMac аналогичное действие можно выразить отдельной зарегистрированной командой выбора строки. Сам файл Lua, `CmdLine.Empty`, `APanel.Visible` и условная функция не исполняются. Равенство одного результата не означает совместимость языка или условий.

Исследованный полезный поднабор: последовательность доступных команд, привязка клавиши к контексту, запись успешных действий, прекращение на ошибке и пользовательская остановка. В текущем собственном контракте нет переменных, циклов, условий Lua, событий запуска, `far.*`, `win.*`, `Plugin.Call`, MoonScript, плагинных панелей FAR и произвольных редакторских API. Полный Lua сам по себе не решает совместимость: потребовалась бы реализация окружения FAR и правил событий, а не только парсер языка.

Реализация находится в [CommandRegistry.swift](../Sources/FarCore/CommandRegistry.swift), [MacroController.swift](../Sources/FarCore/MacroController.swift), [MacroPersistence.swift](../Sources/FarCore/MacroPersistence.swift). Запись ограничена 256 шагами; конфигурация — 100 макросами, 200 привязками и 2 000 000 байт. Загрузка JSON не запускает макросы. Остановка проверяется между командами и не откатывает выполненные шаги. Диалоги и файловые операции доступны для ручного вызова через реестр с обычными подтверждениями; в записываемый поднабор они не входят.

Уровень совместимости P11.3: поведенческая адаптация перечисленного поднабора, **нулевая заявленная исходная совместимость с Lua/MoonScript FAR**. Применимость к другим макросам требует отдельного исследования и тестового примера.

## Интерфейс FarForMac

Меню «Автоматизация»: палитра команд текущего контекста `⌃⌘P`, начало/конец записи `⌃⌘R`, воспроизведение, остановка `⌃⌘.`, импорт/экспорт JSON и последние ошибки. Запись содержит только помеченные в палитре команды: локальные пометки, курсор вверх/вниз, переключение панелей, порядок/режим отображения; отступы, выделение всего текста и номера строк редактора; перенос строк просмотрщика. Навигация с фоновым чтением, диалоги, файловые операции, ввод текста, расширения и shell не записываются. Их существующие команды сохраняют обычные подтверждения при ручном запуске.

Перед воспроизведением проверяется вся последовательность, затем каждый шаг. Фоновая загрузка панели или неподходящий режим отклоняют действие. Смена окна, нажатие клавиши или щелчок останавливают дальнейшие шаги; уже выполненные изменения пометок/буфера не откатываются автоматически. В редакторе изменения доступны обычному Undo. На запуске читаются только данные из `~/Library/Application Support/FarForMac/macros.json`; привязки выключены, пока пользователь явно не включит их в меню. UI поддерживает только `⌃⌘0…9` отдельно для каждого контекста и отвергает импорт других сочетаний с объяснением; публичное ядро допускает более широкий формат для будущих клиентов.

Реестр охватывает меню команд панели и ограниченные команды редактора/просмотрщика. Низкоуровневый ввод текста, все редакторские кнопки, клавиши дополнительных/архивных/сетевых панелей и все внутренние AppKit selectors ещё не унифицированы. Диалог предоставляет команду справки, но не запись ответов или автоматическое подтверждение.
