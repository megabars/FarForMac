# Brackets: эталон до реализации, 06.11.2026

Прочитаны через GitHub закреплённые [Brackets.cpp](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/plugins/brackets/Brackets.cpp), [BrackRus.hlf](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/plugins/brackets/BrackRus.hlf) и [Brackets.lua](https://github.com/FarGroup/FarManager/blob/1a6b02544b339615232078e0551463ef15b73ff9/plugins/brackets/Brackets.lua). Реализация независимая, исходный C++ в продукт не включается.

- Плагин доступен из редактора. Меню: найти, выделить, настройка; одинаковые символы требуют направления. Lua-привязки: Ctrl+[ / Ctrl+] — найти вперёд/назад, Shift добавляет выделение. Для неодинаковых скобок направление определяется самой скобкой.
- Поиск учитывает вложенность выбранной пары, другие виды скобок не образуют общий стек. Выделение включает скобки, не меняет текст и не записывает файл. Без совпадения положение и выделение сохраняются.
- Настройки исходника: одинарные пары `<> {} [] () "" '' %% «»` (без пробелов), двойные `/* */`, `<? ?>`, `<% %>`; приоритет двойных, обработка позиции за скобкой, кавычки, сигнал. У одинаковых символов учитывается непосредственный обратный слеш, а не чётность всех слешей.
- Особенности кода имеют приоритет перед общим описанием: правило кавычек проверяет непосредственно соседние символы, не разбирает строки языка программирования; проверка начальной скобки и последующих кандидатов использует разные значения IgnoreQuotes. BrRight начинает обход с позиции после курсора. Двойные пары сохраняют выбор конкретного символа согласно завершающей поправке OpenW.

Границы: индексы — UTF-16 редактора; настраиваемые символы ограничены BMP без суррогатов/переносов строк (по 10 пар). Независимый от выделения виртуальный курсор FAR, JumpToPair=false и ABI Plugin.Call/LuaMacro не реализованы. AppKit показывает обычный непрерывный блок. Полный перенос плагинного API и сравнительная приёмка с запущенным FAR остаются открытыми.
