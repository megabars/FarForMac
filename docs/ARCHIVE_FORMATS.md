# Архивы: форматы, библиотека и ограничения

Реализация использует системную `libarchive` macOS через C API. На проверенной
машине `archive_version_string()` возвращает `libarchive 3.7.4`, номер версии —
`3007004`. Это версия динамической библиотеки текущей ОС: другая версия macOS
может поставлять другую версию библиотеки. Приложение не запускает внешние
архиваторы. Публичные заголовки взяты из официального выпуска libarchive 3.7.4;
исходный код библиотеки в проект не включён.

| Формат | Список и чтение | Создание и изменение | Пароль |
| --- | --- | --- | --- |
| Обычный ZIP | Да | Да | Незашифрованные архивы |
| ZIP с ZipCrypto | Да | Нет | Извлечение с паролем через C API |
| ZIP с WinZip AES-256 | Да | Нет | Извлечение с паролем через C API |
| Несжатый TAR | Да | Да | Не применяется |
| TAR.GZ, TAR.BZ2, TAR.XZ и другие внешние фильтры | Нет | Нет | Не применяется |
| ZIP64, многотомный и самораспаковывающийся ZIP | Нет | Нет | Не поддерживается |
| 7z, RAR и остальные форматы libarchive | Нет | Нет | Не поддерживается |

Возможности намеренно ограничены этой таблицей, даже если системная библиотека
умеет больше. AES-256 и ZipCrypto проверяются тестами на небольших зашифрованных
ZIP, создаваемых через библиотечный API. Другие схемы шифрования и пароли для
создания архивов не заявлены. Заголовки обычного ZIP доступны без пароля; проверка
пароля, CRC и целостности содержимого выполняется при извлечении. Успешное
открытие списка само по себе не означает успешную проверку всех данных.

## Лимиты чтения и извлечения

Значения `ArchiveLimits.default`:

| Ограничение | Значение |
| --- | --- |
| Число заголовков элементов | 10 000 |
| Размер одного обычного файла | 256 МиБ |
| Общий распакованный размер файлов | 1 ГиБ |
| Общий размер / размер исходного архива | Не больше 1 000 |
| Глубина пути | 128 компонентов |
| Длина пути | 16 384 байта UTF-8 |
| Длина компонента пути | 255 байт UTF-8 |

Список проверяет заявленные размеры и все пути. Извлечение дополнительно считает
фактически прочитанные байты порциями по 64 КиБ, проверяет размер каждого файла и
целостность данных. Сумма размеров и коэффициент распаковки проверяются без
переполнения целых чисел. Лимиты можно задать через программный API; настройки
интерфейса для их изменения не предусмотрены.

Все имена проверяются до создания рабочей папки, включая элементы вне выбранной
части архива. Отклоняются абсолютные пути, `..`, внутренние `.` и пустые
компоненты, обратная косая черта, двоеточие и NUL. Начальное `./` и завершающий
слеш каталога нормализуются. Имена приводятся к NFC; повторные имена, коллизии
регистра и Unicode, а также конфликт «файл является родителем другого элемента»
отклоняются. Исходные имена ZIP дополнительно проверяются до нормализации внутри
библиотеки. Символьные и жёсткие ссылки, устройства, FIFO и другие специальные
элементы не извлекаются: архив с такими элементами отклоняется целиком.

Извлечение создаёт только новую приватную временную папку приложения с правами
`0700`; обычные рабочие файлы имеют права `0600`. Папки и файлы открываются через
дескриптор родителя, с запретом следовать символьным ссылкам и с исключительным
созданием файлов. Произвольный внешний каталог назначения не принимается этим
API. Дальнейшее копирование в пользовательское назначение выполняет обычный
механизм файловых операций с разрешением конфликтов.

Пароль передаётся библиотеке в памяти, не включается в командную строку, журналы,
настройки или снимок архива. Рабочие копии содержат открытый текст: они существуют
до закрытия использующего их окна либо завершения операции, затем удаляются.
Удаление временного файла не является гарантированным физическим стиранием
данных с накопителя. Архив повторно проверяется по устройству, inode, размеру и
времени изменения/метаданных перед операцией и после чтения; изменение источника
требует открыть его заново. Отмена кооперативная между заголовками и порциями
данных. Жёсткое прерывание заблокированного системного ввода-вывода не обещается.

## Лицензии и источники

Публичные заголовки распространяются по BSD 2-Clause. Полный текст уведомления
сохранён в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) и самих заголовках.
Системная библиотека поставляется macOS; её состав и сопутствующие уведомления
определяются поставкой Apple.

- [Официальный archive.h, libarchive 3.7.4](https://github.com/libarchive/libarchive/blob/v3.7.4/libarchive/archive.h)
- [Официальный archive_entry.h, libarchive 3.7.4](https://github.com/libarchive/libarchive/blob/v3.7.4/libarchive/archive_entry.h)
- [Официальная документация параметров ZIP](https://github.com/libarchive/libarchive/blob/v3.7.4/libarchive/archive_write_set_options.3)
